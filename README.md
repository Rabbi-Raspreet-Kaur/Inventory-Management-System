# Object-Oriented Inventory & Management System

A robust Java desktop/backend management application built using core **Object-Oriented Programming (OOP)** principles and **JDBC (Java Database Connectivity)** for seamless, high-performance communication with a MySQL database.

Designed with a modular architecture to ensure clean separation of concerns, efficient data manipulation, record tracking, and memory-optimized entity handling.

## 🚀 Features
- **Object-Oriented Architecture:** Implements encapsulation, inheritance, polymorphism, and abstraction across core domain entities.
- **Database Connectivity (JDBC):** Secure connection management with MySQL using parameterized SQL queries.
- **Modular Design:** Clear separation between service logic, DAO layer, connection management, and models.

## 🛠️ Tech Stack
* **Language:** Java (JDK 17+)
* **Database:** MySQL
* **Connectivity:** JDBC Driver (`mysql-connector-j`)
* **Build Tool:** Maven
* **Design Patterns:** DAO, Singleton, Factory
